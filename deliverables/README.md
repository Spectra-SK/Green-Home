# Deliverables

This directory holds the Megathon submission artifacts. Per `CLAUDE.md`,
the following files are produced here as each milestone is written up
(not fabricated ahead of time):

- `M1.pdf` — due 10:00 PM, 10th Oct. Max 2 pages, double-blind (team number only).
- `M2.pdf` — due 4:00 AM, 11th Oct. Max 2 pages, plus a git push to `main`.
- `final_report.pdf` — due 11:00 AM, 11th Oct.

The final submission also needs a root-level `README.md` (run commands
only), `LICENSE` (MIT), and a 4-minute video link.
